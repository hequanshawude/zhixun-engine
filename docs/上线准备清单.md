## 已修复的准备阶段问题

- 无标签流增加独立训练集入口，避免初始化要求标签而无法启动。
- 模型随机种子贯通各训练入口；多批验证与隔离间隔已接入，75 项检查通过，版本与交付材料已冻结。
- 多批初始化现在合并所有初始化批次进行训练。
- 回归任务以较低误差选历史最佳；多分类不再误用回归偏置校准。
- 缺特征列不再静默替换成其他列；当前批仍不得参与候选训练。
- 回滚引用的历史模型元信息不再原地修改；失败候选不会盲目触发历史模型替换。
- 全批耗时计入运行账本；LLM 非法响应后降级仍保留已返回 Token 用量。
- 无标签或仅允许保持时跳过 LLM 调用；日志密钥脱敏、运行目录避免重名。
- 镜像默认关闭云端访问并将运行日志写入挂载输出目录。
- 规则/探索策略支持按批检查点、输入和输出校验、中断恢复；独立进程恢复对照通过，平台提交确认与去重仍待 SDK。
- 模型决策支持完整嵌套 JSON；非法回复采用规则降级，已知用量保留、未知用量单独标记，连续失败熔断。57 项自动检查与 6 项本机/容器模拟接口验收通过，实际平台接口仍待验证。

## 平台上线前可重复执行

1. 使用项目 `.venv` 执行 `scripts/preflight.py`；保存 `out/preflight` 全目录。
2. 阅读 `report.json`：运行成功与超过基线是两个独立结论，不删掉负增益实验。
3. 保留源代码、配置、环境清单和 SHA-256 manifest。当前环境清单是 Windows 实测版本，不是已验证的 Linux 锁文件。
4. 在有 Docker 的机器上构建镜像，用 README 中断网命令演练；测量镜像大小、峰值内存与逐批耗时。
5. 准备 SwanLab 项目与队伍信息；账号密钥只通过环境注入，不写入代码或交付包。云端访问需用户账号配合。

## 平台开放后按顺序接入

1. 下载公开训练集、验证集、官方基线与评测脚本、SDK、《实验记录规范》；记录版本和文件哈希，保存原始公开包，不索取隐藏数据。
2. 确认任务类型、目标列、样本 ID、特征顺序、标签编码、缺失值规则、时间顺序、主指标、预测格式和逐批握手。确认标签可见时点、查询配额及延迟反馈机制；按此修改数据/输出适配层。
3. 确认正式资源上限、超时、可携带权重、容器启动参数、输出路径和故障重试语义；把本地演练参数替换为官方值。
4. 核实 PyTRiO 授权模型与实际接口，特别是“统一离线环境”中允许的模型服务访问方式。确认前不得擅自启用外网端点或其他来源模型。
5. 按日志规范核对初始化训练、数据版本、模型参数、候选失败、耗时、Token、标注查询、决策和评估。初始化训练成本已计入本地账本，仍需与官方计量统一。验证云端完整归档并取得可查询链接。
6. 增加 SDK 级故障测试：无标签、迟到标签、服务超时、非法 JSON、预算耗尽、空批次、容器重启。训练工作进程已有超时终止，仍需按平台要求实现整个批次的时限与资源约束；当前保护范围见《运行保护验证》。
7. 在公开集固定时序切分上比较官方静态模型、规则策略、策略记忆、授权 LLM；保存所有实验，统一随机种子和预算，不以候选验证增益代替实际流预测增益。
8. 以官方脚本验证三项门槛后冻结提交：全阶段按时完成、记录完整、综合性能不低于官方基线。任一未通过不得声称可正式提交。
