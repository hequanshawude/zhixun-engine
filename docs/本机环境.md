## 日常使用

- 双击根目录 `run-demo.cmd`：运行本地演示，无需云端账号。
- 双击 `check-project.cmd`：运行完整自检，结果在 `out/preflight`。
- 双击 `login-cloud.cmd`：用项目环境登录 SwanLab。先在官方账号设置页复制 API Key，再在窗口的隐藏输入提示中粘贴；脚本会验证账号是否可用。密钥由 SwanLab 官方工具保存在用户目录，不写入项目脚本。
- 重建镜像：在项目 PowerShell 执行 `./scripts/build-image.ps1`。脚本为当前进程补齐 Docker 路径，并使用电脑已经启用的本地代理；不改全局网络设置。镜像下载需要网络。
- 环境版本：`requirements-windows.lock.txt` 与 `requirements-linux.lock.txt` 分别保存 Windows 和容器实际安装版本，不能交叉使用。项目本身通过 `pip install --no-deps --no-build-isolation -e .` 安装。

本地模型实验与容器使用不同 Python/依赖版本，数值结果可能不同。正式提交时应冻结并复用最终容器环境。
