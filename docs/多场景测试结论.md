# 多场景测试结论（2026-11-09）

本文为接入探索功能前的历史对照。后续修改及新种子结果见 [策略探索验证](策略探索验证.md)。

已完成 6 种合成场景 × 3 个数据种子 × 2 种更新策略，共 36 次运行，对应 18 组独立生成的数据。所有运行成功；云端读回核验 36/36 通过，逐点核对了系统与静态模型曲线、汇总增益、数据哈希、配置密钥脱敏和每次 13 条决策，共 468 条决策记录。

## 本轮发现

| 场景 | 相对本地静态模型的平均 F1 增益 |
|---|---:|
| 无漂移 | +0.0059 |
| 输入分布变化 | +0.0144 |
| 概念漂移 | +0.0339 |
| 类别比例变化 | +0.0190 |
| 突变 | +0.0563 |
| 混合漂移 | +0.0585 |

这 18 组数据中两种策略均超过本地静态模型，但规则与策略记忆的动作和分数完全一致，因此不能声称策略自进化带来了额外收益。当前路由主要采用规则先验，只在已有动作积累足够正反馈时复用记忆；已有探索选择函数尚未接入该路径。

## 后续顺序

1. 增加受预算与候选验证约束的策略探索，保留规则对照；用预先固定的新种子检查收益和退化情况。
2. 补齐初始化成本与强制超时，并覆盖多分类、回归以及延迟标签等接口场景。
3. 官方平台资料到位后，接入 SDK、正式数据、官方静态基线、评分和记录规范，再判断是否满足参赛要求。

本轮仅为二分类合成数据开发验证，三个种子不足以证明普遍有效，也不是官方比赛分数。类别比例变化由截距调整生成，不是严格纯标签漂移。耗时采用本地成本估算，未覆盖完整初始化和全部云端同步开销。

## 复现

双击项目根目录 `run-benchmark.cmd` 可重新运行 36 次云端实验，需要联网；每次生成独立报告目录。报告目录保留结果、源代码哈希、预测和本地日志。读回核验脚本为 `scripts/verify_benchmark.py`，参数为对应报告目录。
