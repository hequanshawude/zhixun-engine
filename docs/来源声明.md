## 4. 对赛方代码的修改

1. **`baselines/train.py`：按验证集保留最优 epoch。** 原实现只保存最后一个 epoch。
   修改不涉及网络结构、优化器语义或数据边界，公开验证集仅用于选择 epoch。
4. **Net2Net 加宽工具（`scripts/widen_cpu_checkpoint.py` / `selftrain/widen.py`）。**
   按赛规"显式实现兼容的权重迁移"的要求，把隐藏层复制式加宽并校验前向漂移
   （0.04%–0.30%），不伪装成原模型续训。
5. **运行时补丁（`selftrain/patcher.py`）。** 镜像启动时把平台包复制到可写目录，
   给 `baselines/train.py` 打"保留验证集最优 epoch"补丁（幂等）。这是为了让提交结果
   与本地验证一致，不改变网络、优化器语义或数据边界。
6. **权重衰减开关（`model.py` 内 `meta["weight_decay"]`）。** 实验证明有害，
   默认 0，不产生任何行为差异。


两处修改都记录在 `training.json` 的 `source_sha256` 与检查点元信息里，可逐轮核对。

## 5. 原创部分

`selftrain/`（数据流、漂移检测、归因、动作菜单、预算账本、晋级闸门、实验记录、CPU 续训驱动）、
`scripts/` 下的全部工具脚本、`docs/` 下的全部分析文档，均为本项目原创。

## 6. 未使用的内容

- 未使用任何 Embedding 模型（赛规禁止）；
- 未联网搜索、未调用 PyTRiO 以外的任何外部模型 API；
- 未使用赛方隐藏测试集的任何样本或标签；
- 未将模型权重打包进镜像。
