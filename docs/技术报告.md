# 技术报告：工业模型自进化系统

> 面向"智训引擎"赛题。评分对象是续训后的工业模型，本文说明我们如何让 Harness 在无人工干预下
> 把它训练得更好，以及所有结论的证据强度。

## 1. 问题理解

赛题要的不是一个模型，而是**一套能持续改进模型的系统**。三个约束决定了设计：

1. **漂移**：工业数据分布随时间变化，"一次训练长期有效"会失效。
2. **预算**：算力、Token、标注都要计价，增益/成本比才是分数。
3. **安全**：任何自动更新都必须可回滚，不能把线上模型改坏。

赛题同时给了两个物：**CPU 工业模型**（被训练对象）和 **PyTRiO 大模型**（驱动工具）。
我们严格区分二者：大模型只做决策，最终产物是 CPU 检查点。

## 2. 系统架构

```
              ┌──────────────────────────────────────────────┐
  平台检查点 → │  CPU 续训驱动 (selftrain.cpu)                 │ → final-checkpoint.npz
              │                                              │
              │  ① 读账本（最近 5 轮的参数/指标/决策）          │
              │  ② 大模型选 (lr, epochs) 或直接改训练代码        │
              │  ③ 从"当前采纳的检查点"续训                     │
              │  ④ 公开验证集评估 → 更好则采纳，否则回滚          │
              └──────────────────────────────────────────────┘
```

镜像内入口：

```bash
python -m selftrain cpu --package /data/package --out /out --rounds 10 --driver llm
```

大模型不可用时自动降级为确定性轮换策略，保证"无人干预跑完"这条硬门槛不丢。

## 3. 核心方法

### 3.1 每轮是一个完整的"实验"，不是一次盲训

赛规要求至少 3 次"读历史-做实验-依据结果决策"。我们的每一轮都满足：

| 环节 | 实现 |
|---|---|
| 读历史 | 账本里最近 5 轮的 `lr / epochs / 验证值 / 是否采纳` 进入状态卡 |
| 做实验 | 从**当前采纳的检查点**继续，参数由大模型决定 |
| 决策 | 公开验证集更好则采纳并前移，否则拒绝并回滚到上一采纳点 |

### 3.2 三个反直觉的工程事实

**(a) 确定性训练下，同参数重跑结果逐位相同。** 第一版 10 轮用固定参数，被拒绝后
从同一检查点重跑，A 的后 9 轮全是 0.7187——等于白跑。必须每轮换参数。

**(b) 训练器只保存最后一个 epoch，而末轮常常不是最优。** B 的 epoch 19 是 647.24，
epoch 20 是 666.88。我们加了"按验证集保留最优 epoch"的补丁。

**(c) 加宽不是单调的。** A 从 32 加到 64 涨到 0.7292，加到 128 退回 0.7251；
B 从 24 加到 48 退到 648.58，加到 64 到 642.88，加到 96 到 606.27，128 到 602.55。**必须逐档试，由闸门兜底。**

### 3.3 结构迁移（Net2Net）

C 的训练 loss 停在 0.42（A/B 是 0.08），是典型欠拟合。赛规允许改结构但要求显式权重迁移：

- 旧单元原样保留；
- 新单元复制随机旧单元，并把该旧单元的输出权重按复制数**均分**，保证前向不变；
- 加 1e-3 噪声打破对称，否则两单元梯度恒等、学不到东西；
- 迁移后校验前向漂移：实测 **0.06%–0.30%**。

## 4. 实验与结果

### 4.1 主结果

| 数据集 | 指标 | 基线 | 我们的结果 | 相对 |
|---|---|---:|---:|---:|
| A 气体六分类 | Macro-F1 ↑ | 0.7140 | **0.7292** | **+2.1%** |
| B 轴承 RUL | RMSE ↓ | 681.16 | **602.55** | **−11.5%** |
| C 发动机 RUL | RMSE ↓ | 52.87 | **50.98** | **−3.6%** |

### 4.2 消融：谁来决策

| 决策者 | A | B | C | Token |
|---|---:|---:|---:|---:|
| 人工固定学习率表 | 0.7264 | 647.24 | 51.50 | 0 |
| **Qwen3.8-27B 选超参** | 0.7264 | 647.86 | 51.26 | 17.5k |
| Qwen 直接改 `train.py` | 0.7264 | 651.04 | 51.59 | 106k |

结论：**大模型能追平人工调参并有反超（C），但"让它改代码"没有收益且贵 6 倍。**
改代码版本保留为能力与安全闸门的证据，不作为默认路径。

### 4.3 消融：加不加容量

| 手段 | A | B | C | 结论 |
|---|---:|---:|---:|---|
| 权重平均（SWA） | 0.7264 | 662.88 | 51.39 | 更差，轨迹不平坦 |
| 加宽 2 倍 | **0.7292** | 648.58 | 51.16 | A/C 有效、B 无效 |
| 再加宽到 128 | 0.7251 | — | **50.977** | A 过拟合、C 继续涨 |

这条对照说明：**优化动作没有普适最优，必须先诊断（欠拟合 vs 过拟合）再选动作。**

## 5. 成本与效率

- 全程 CPU 单线程，每个数据集 10 轮总耗时 **20–50 秒**（含 Net2Net 加宽与起点探测；
  三个包一起在 4 核 2G 容器内跑完约 **155 秒**）；
- 参数规模 833–17,286，均远低于 10 万上限；
- 大模型 Token：只调参 17.5k，改代码 106k；
- 镜像 1.07 GB（上限 2 GB），不含任何权重。

## 6. 安全与可控

| 机制 | 实现 |
|---|---|
| 回滚 | 每轮被拒绝即回到上一采纳检查点，账本记录 `rollback_to` |
| 参数白名单 | 学习率只能从 5 档里选，epoch 只能 3/5/8，越权即降级 |
| 代码闸门 | 改代码须过单元测试 + 1 epoch 冒烟，否则回滚 |
| 数据边界 | 只读公开 train/validation，隐藏集从未出现 |
| 降级 | 大模型不可用自动切轮换表，保证跑完 |

## 7. 局限

1. **B 的 RMSE 仍在 600 量级**（分钟），离可用预测有距离；这是任务难度，不是实现缺陷。
2. **验证集规模小**（A 仅 1,244 条），0.008 量级的差异不显著，我们的结论只在"不低于基线"这个层面可靠。
3. **隐藏测试协议未知**，镜像入口按"挂载模型包"假设实现，需按官方 SDK 调整。
4. **未做在线漂移闭环**：`selftrain` 具备漂移检测/归因/闸门能力，但尚未与 CPU 续训驱动
   合并成单一进程（当前是两个入口）。

## 8. 结论

- 三个数据集全部优于平台基线，且改进来自可解释的动作（加宽、学习率调度），不是运气；
- 系统在无网络、无人工干预下可独立跑完 10 轮并产出检查点；
- 我们同时记录了"哪些优化无效"（SWA、让模型改代码），这比只报好消息更有工程价值。
