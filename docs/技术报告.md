# 技术报告：工业模型自进化系统

> 面向"智训引擎"赛题。评分对象是续训后的工业模型，本文说明我们如何让 Harness 在无人工干预下
> 把它训练得更好，以及所有结论的证据强度。

## 1. 问题理解

赛题要的不是一个模型，而是**一套能持续改进模型的系统**。三个约束决定了设计：

1. **漂移**：工业数据分布随时间变化，"一次训练长期有效"会失效。
2. **预算**：算力、Token、标注都要计价，增益/成本比才是分数。
3. **安全**：任何自动更新都必须可回滚，不能把线上模型改坏。

赛题同时给了两个物：**CPU 工业模型**（被训练对象）和 **PyTRiO 大模型**（驱动工具）。
我们严格区分二者：大模型只做决策，最终产物是 CPU 检查点。

## 2. 系统架构

```
              ┌──────────────────────────────────────────────┐
  平台检查点 → │  CPU 续训驱动 (selftrain.cpu)                 │ → final-checkpoint.npz
              │                                              │
              │  ① 读账本（最近 5 轮的参数/指标/决策）          │
              │  ② PyTRiO Qwen 选 (lr, epochs)                 │
              │  ③ 从"当前采纳的检查点"续训                     │
              │  ④ 公开验证集评估 → 更好则采纳，否则回滚          │
              └──────────────────────────────────────────────┘
```

镜像内入口：

```bash
python -m selftrain cpu --packages-root /data --out /out --rounds 10 --driver llm --widen auto
```

镜像会把只读模型包复制到输出目录，并在工作副本中启用“保留验证集最优 epoch”的训练补丁。
大模型不可用时自动降级为确定性轮换策略；每轮账本记录实际决策来源，
因此降级运行不能作为“大模型驱动”的证据。默认入口不启用 SwanLab 云端上传。

## 3. 核心方法

### 3.1 每轮是一个完整的"实验"，不是一次盲训

赛规要求至少 3 次"读历史-做实验-依据结果决策"。我们的每一轮都满足：

| 环节 | 实现 |
|---|---|
| 读历史 | 账本里最近 5 轮的 `lr / epochs / 验证值 / 是否采纳` 进入状态卡 |
| 做实验 | 从**当前采纳的检查点**继续；正常联网时由大模型选参数，失联时由固定表选参数 |
| 决策 | 公开验证集更好则采纳并前移，否则拒绝并回滚到上一采纳点 |

### 3.2 三个反直觉的工程事实

**(a) 确定性训练下，同参数重跑结果逐位相同。** 第一版 10 轮用固定参数，被拒绝后
从同一检查点重跑，A 的后 9 轮全是 0.7187——等于白跑。必须每轮换参数。

**(b) 训练器只保存最后一个 epoch，而末轮常常不是最优。** B 的 epoch 19 是 647.24，
epoch 20 是 666.88。我们加了"按验证集保留最优 epoch"的补丁。

**(c) 加宽不是单调的。** A 从 32 加到 64 涨到 0.7292，加到 128 退回 0.7251；
B 从 24 加到 48 退到 648.58，加到 64 到 642.88，加到 96 到 606.27，128 到 602.55。**必须逐档试，由闸门兜底。**

### 3.3 结构迁移（Net2Net）

C 的训练 loss 停在 0.42（A/B 是 0.08），是典型欠拟合。赛规允许改结构但要求显式权重迁移：

- 旧单元原样保留；
- 新单元复制随机旧单元，并把该旧单元的输出权重按复制数**均分**，保证前向不变；
- 加 1e-3 噪声打破对称，否则两单元梯度恒等、学不到东西；
- 迁移后校验前向漂移：实测 **0.06%–0.30%**。

## 4. 实验与结果

### 4.1 可复现的十轮结果（公开验证集）

| 数据集 | 指标 | 原包基线 | 已上传镜像的断网预演 | 本机 Qwen 联网复跑 | 单独调优的最佳检查点 |
|---|---|---:|---:|---:|---:|
| A 气体六分类 | Macro-F1 ↑ | 0.7140 | **0.7279** | 0.7279 | 0.7292 |
| B 轴承 RUL | RMSE ↓ | 681.16 | **624.42** | 625.67 | 602.55 |
| C 发动机 RUL | RMSE ↓ | 52.87 | **51.49** | 51.56 | 50.98 |

断网预演使用已上传镜像的默认入口、赛方原版模型包、4 核/2 GiB 限额，A/B/C 各完成
10 轮、失败 0；因没有网络与凭据，实际 Qwen 决策 **0/30** 轮。本机联网复跑
Qwen 决策 **30/30** 轮，记录已同步 SwanLab。最后一列来自**另行调优的检查点**，
不是当前镜像默认十轮运行的产物，不能当作平台试运行或隐藏测试成绩。
按断网预演相对原包公开验证基线计算，A 提升 1.94%，B 的 RMSE 降低 8.33%，
C 的 RMSE 降低 2.60%；三项等权平均改善 4.29%。平台正式评分口径与隐藏测试结果尚未知。

### 4.2 早期消融：谁来决策

| 决策者 | A | B | C | Token |
|---|---:|---:|---:|---:|
| 人工固定学习率表 | 0.7264 | 647.24 | 51.50 | 0 |
| **Qwen3.8-27B 选超参** | 0.7264 | 647.86 | 51.26 | 17.5k |
| Qwen 直接改 `train.py` | 0.7264 | 651.04 | 51.59 | 106k |

这组消融使用早期配置，**不能与上表的十轮运行直接比较**。在该配置中，Qwen
调参在 C 上优于固定表；直接改代码的收益较低、Token 约为调参的 6 倍，
因此当前镜像只让 Qwen 选择白名单内的超参数。

### 4.3 消融：加不加容量

| 手段 | A | B | C | 结论 |
|---|---:|---:|---:|---|
| 权重平均（SWA） | 0.7264 | 662.88 | 51.39 | 更差，轨迹不平坦 |
| 加宽 2 倍 | **0.7292** | 648.58 | 51.16 | A/C 有效、B 无效 |
| 再加宽到 128 | 0.7251 | — | **50.977** | A 过拟合、C 继续涨 |

这条对照说明：**优化动作没有普适最优，必须先诊断（欠拟合 vs 过拟合）再选动作。**

### 4.4 与客观评分维度对应的本地自测

| 维度 | 公开验证集代理指标 | 证据边界 |
|---|---|---|
| 平均提升 | 断网镜像十轮结果的三任务相对改善等权平均 4.29% | 非平台隐藏测试得分 |
| 最差阶段与恢复 | 只部署优于当前已采纳检查点的候选，部署序列最差点为起点；A/B/C 最长连续拒绝为 8/9/3 轮 | 候选可能退步，回滚避免其进入部署序列 |
| 稳定性 | 三任务各跑满 10 轮，失败 0；公开验证集的最终值均优于原包基线 | 尚无多随机种子及隐藏集稳定性结论 |
| 资源效率 | 断网镜像三任务累计 147.88 秒、0 Token；本机 Qwen 复跑累计 172.79 秒、14,500 Token | 为各包运行时间之和，不含平台排队与启动时间 |

## 5. 成本与效率

- 已上传镜像在 4 核/2 GiB 断网容器中完成三包十轮预演，累计训练约 148 秒；
  其中 C 为 119.60 秒，是主要耗时来源。
- 本机 Qwen 联网复跑三包累计约 173 秒、14,500 Token；早期“改代码”消融另耗约 106k Token。
- 参数规模 833–17,286，低于 10 万上限；镜像解包后约 1.07 GB，上传归档约 220.6 MiB，均不含模型权重。

## 6. 安全与可控

| 机制 | 实现 |
|---|---|
| 回滚 | 每轮被拒绝即回到上一采纳检查点，账本记录 `rollback_to` |
| 参数白名单 | 学习率只能从 5 档里选，epoch 只能 3/5/8，越权即降级 |
| 代码闸门 | 改代码须过单元测试 + 1 epoch 冒烟，否则回滚 |
| 数据边界 | 只读公开 train/validation，隐藏集从未出现 |
| 降级 | 大模型不可用自动切轮换表，保证跑完 |

## 7. 局限

1. **B 的 RMSE 仍在 600 量级**（分钟），离可用预测有距离；这是任务难度，不是实现缺陷。
2. **验证集规模小**（A 仅 1,244 条），0.008 量级的差异不显著，我们的结论只在"不低于基线"这个层面可靠。
3. **平台执行协议未确认**：镜像入口按 `/data` 挂载模型包、`/out` 收集产物设计；当前 v1 虽通过上传侧校验，试运行返回“作品镜像未获当前执行环境准入”。尚无平台试运行或隐藏测试成绩。
4. **未做在线漂移闭环**：`selftrain` 具备漂移检测/归因/闸门能力，但尚未与 CPU 续训驱动
   合并成单一进程（当前是两个入口）。

## 8. 结论

- 在本地公开验证集上，已上传镜像的断网预演与 Qwen 联网复跑均优于原包记录的基线；因缺少平台试运行与隐藏测试，尚不能推断正式成绩；
- 系统在无网络、无人工干预下可独立跑完 10 轮并产出检查点；
- 我们同时记录了"哪些优化无效"（SWA、让模型改代码），这比只报好消息更有工程价值。

## 9. 来源与合规声明

工业模型训练起点和公开 train/validation 来自赛方 A/B/C 模型包，派生数据分别对应
[UCI Gas Sensor Array Drift](https://archive.ics.uci.edu/dataset/224/gas)、
[XJTU-SY Bearing Datasets](https://github.com/WangBiaoXJTU/xjtu-sy-bearing-datasets) 与
[NASA C-MAPSS](https://data.nasa.gov/dataset/cmapss-jet-engine-simulated-data)。
决策模型为经 PyTRiO 调用的 `Qwen/Qwen3.8-27B` 基础模型；未把其权重或工业模型权重装入镜像。
镜像内原创代码、训练补丁、依赖清单与完整来源声明见
[公开源码仓库](https://github.com/hequanshawude/zhixun-engine) 的 `docs/来源声明.md`。
训练只读取赛方公开训练/验证数据，未使用隐藏测试样本或标签。

| 组成 | 来源与使用范围 | 本作品中的处理 |
|---|---|---|
| A/B/C 训练起点 | 赛方下发的 CPU 模型包 | 从原始检查点开始续训；镜像不预装权重 |
| 公开数据 | 赛方模型包内的 `public/train.jsonl`、`public/validation.jsonl` | 用于训练、选择 epoch 和采纳/回滚；不读取隐藏集 |
| 决策模型 | PyTRiO 官方服务中的 `Qwen/Qwen3.8-27B` 基础模型 | 仅给出白名单内的学习率与 epoch 建议；最终工业模型由 CPU 训练器产出 |
| 实验记录 | 本地 JSONL 和可选 SwanLab 云端项目 | 逐轮保存候选值、采纳结果、实际决策来源、Token 与最终检查点 |

针对赛方原版 `baselines/train.py`，运行时在**可写工作副本**上打“保留最佳 epoch”补丁；
Net2Net 加宽通过复制权重并分摊输出权重实现，随后校验前向漂移。
上述修改不会回写赛方原始只读模型包。项目源码以公开 GitHub 仓库为准，
完整依赖许可、数据引用和修改说明见仓库内 `docs/来源声明.md`。

已提交的 SwanLab 实验链接对应**本机 Qwen 联网复跑的 A 包**，
不能替代平台运行记录；B/C 的本机十轮运行也有各自云端记录。
平台执行协议和镜像准入问题得到确认后，应以平台试运行生成的账本、
模型检查点和隐藏测试结果补充本报告。
