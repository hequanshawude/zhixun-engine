## 仍需官方协议

当前镜像通过 PyTRiO 远程服务加载训练权重。赛题又称正式评测为统一离线环境，需要赛方明确是否提供允许访问的模型服务接口。已下载的适配器只含 LoRA 增量权重；按[官方部署说明](https://docs.pytrio.com/docs/guide/download)，完全离线运行还需 Qwen3.5-4B 基模及本地推理依赖。暂未将数 GB 基模和推理框架塞入镜像，因为官方内存、磁盘、镜像大小、CPU/GPU 与超时限制尚未公布。当前 `zhixun-engine:pytrio-preflight` 不能据此宣称通过正式离线评测。

正式平台发布后，先确认模型服务例外或本地权重部署规则，再按官方数据协议和评测脚本做整套容器验收。若允许远程 PyTRiO，镜像已有 SDK、分词器和受控客户端；若必须完全离线，则按官方资源上限决定是否把基模与 LoRA 适配器打包并改成本地推理入口。
