# 交付包说明

这是平台开放前准备版的冻结归档，不是已通过官方评测的正式提交包。

## 包含内容

- `selftrain`、`configs`、`scripts`、`tests`：本次冻结的代码、配置、运行和验证脚本。
- C-MAPSS FD001 首次回放与独立设备闸门复验的结果摘要、云端链接及复现说明；原始数据和处理后 CSV 不入包。
- Dockerfile、依赖清单、运行入口与文档。
- `out` 下筛选的测试结果、实验汇总、云端链接和镜像元数据。历史报告保留失败与负收益结果；原本机绝对路径仅作为历史记录。
- `RELEASE-MANIFEST.json`：每个归档文件的 SHA-256；压缩包旁的 `.sha256` 用于校验整个 ZIP。

不包含账号凭据、训练数据、LoRA 权重、恢复检查点、`.venv` 或 Docker 镜像二进制。原冻结镜像约 724 MB；最新 27B 准备镜像约 1.07 GB，详见 [Qwen27B 真实数据对照](Qwen27B真实数据对照.md)。本包提供镜像构建材料，不能把 ZIP 当作可直接 `docker load` 的镜像。

## 使用顺序

1. 先阅读 README 与《上线准备清单》。最新配置说明见《配置生效与交付验证》。
2. 新电脑可按主 Dockerfile 联网构建；`Dockerfile.local` 只适用于已有本地基础镜像时刷新代码。Windows 和 Linux 依赖锁文件不可互换。
3. 本地运行需 Python 3.10 或以上并安装依赖。云端使用者需自行登录自己的 SwanLab 账号，配置正确工作区；本包不携带登录凭据。
4. 按脚本复验后再接正式数据。日志、预测、检查点和测试临时目录应使用独立路径。

现有合成数据结果不代表正式比赛成绩。默认仍使用固定规则；此前探索策略相对规则为 4 胜、1 平、13 负，没有将其提升为默认方案。

重新归档可运行 `scripts/package_release.py`。它按文件白名单打包，并读回 ZIP 核对每个文件的哈希；不自动上传、发布或提交。
