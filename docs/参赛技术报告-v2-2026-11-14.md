# 智训引擎参赛技术报告（v2 候选）

日期：2026-11-14。源码：[GitHub 仓库](https://github.com/hequanshawude/zhixun-engine)，对应提交 `0339d93a8e66c9c558059462757de5976cacf1ac`。本报告区分本地公开验证、平台旧版试运行与尚未得到的新版隐藏成绩。

## 1. 任务与方案

赛题要求从平台给出的 CPU 工业模型检查点出发，对 A 气体六分类、B 轴承剩余寿命、C 发动机剩余寿命分别完成 10 轮优化。评分对象是续训后的工业模型；驱动 Harness 的大模型用于读取历史、提出实验参数和决定采纳或回滚。本候选使用平台允许的 `Qwen/Qwen3.8-27B` 基础模型，通过 PyTRiO 调用。

每轮读取最近的指标与决策账本，由 Qwen 在受限学习率及训练轮数集合中选择动作；从当前被采纳的检查点继续训练，在公开验证集上评估。若候选进步则采纳，否则回到上一个已采纳检查点。每轮保存学习率、训练轮数、候选指标、累计最佳指标、模型来源和采纳结果，至少满足 3 次完整的“读历史—做实验—依据结果决策”。

针对任务差异，A 在最终检查点中加入仅用公开训练数据拟合的气体类别确认器；B/C 在最终检查点中加入仅用公开训练数据拟合的树修正器。三组均先训练工业模型，再把修正参数写入运行时生成的最终检查点。镜像不预装工业权重、公开数据或密钥。

## 2. 本地完整复跑结果

候选镜像在 4 CPU、2 GiB 容器内从官方 CPU 模型包完成三组各 10 轮，三组实际 Qwen 决策均为 10 次，失败数为 0。A/B/C 分别消耗 4,770、4,870、4,856 Token。以下均为**本地公开验证集**指标，不能当作平台隐藏成绩。

| 组别 | 指标 | 官方起点 | 直接 27B 续训检查点 | 本候选最终检查点 |
|---|---|---:|---:|---:|
| A 气体六分类 | Macro-F1 ↑ | 0.714030 | 0.727878 | **0.911696** |
| B 轴承 RUL（分钟） | RMSE ↓ | 681.159833 | 612.982104 | **557.849033** |
| C 发动机 RUL（循环） | RMSE ↓ | 52.868573 | 51.578167 | **50.039379** |

相对官方起点，A 的 Macro-F1 增加 0.197666；B 的 RMSE 降低 123.310800（约 18.1%）；C 的 RMSE 降低 2.829193（约 5.4%）。最终检查点经独立进程重新加载、保存后重载和官方 `baselines.predict` 入口复核，三组公开验证预测均无漂移。详细运行证据见仓库中的 [`docs/三组最终模型候选-2026-11-14.md`](https://github.com/hequanshawude/zhixun-engine/blob/main/docs/%E4%B8%89%E7%BB%84%E6%9C%80%E7%BB%88%E6%A8%A1%E5%9E%8B%E5%80%99%E9%80%89-2026-11-14.md)。

SwanLab [本次运行记录归档](https://swanlab.cn/@hequan/zhixunyinqing/runs/mcv9hr59)从已完成的本地训练账本事后同步，包含三组各 10 轮的指标和决策，并在配置中明确标为 `retrospective_archive_of_completed_training`。它不是平台试运行日志，也不是实时云端训练采集；原始逐轮日志与检查点仍保存在本地运行输出中。

## 3. 与旧版平台结果的边界

此前 v1 唯一一次平台试运行的隐藏结果：A Macro-F1 0.880865、B RMSE 673.005512、C RMSE 56.622512。v1 的 A 公开验证曾达到 0.977789，本机未复现该公开高值；因此，虽然新候选 A 的本地公开值为 0.911696，**目前不能认定其隐藏成绩超过 v1**。B/C 的新本地结果也不能直接推断隐藏集收益。

平台还需验证它是否按官方预测入口加载含修正器的最终检查点。若平台只接受原版模型结构，新候选的本地收益可能无法体现。镜像可用只表示归档处理完成，不表示训练、预测、评测通过。应先进行一次受控试运行，检查模型加载、三组十轮和隐藏指标，再决定是否设为正式版本。

## 4. 复现与交付

本候选使用 `Dockerfile.triad-27b-candidate-20261114`。提交镜像的 `docker save` 归档 SHA-256 为 `a5362b87d1466db0727590ade2ae5a29b118d0596ccf4616b34070b6c998e2cd`；平台显示为“镜像 5”，上传时间 2026-11-14 21:35:43，归档约 220.7 MiB。源码提交为上述 GitHub commit。镜像运行时从平台挂载的官方 A/B/C 包读取初始检查点与公开数据，每轮输出日志和检查点，最终生成 `final-checkpoint.npz`。

公开开发数据的来源为 [UCI Gas Sensor Array Drift](https://archive.ics.uci.edu/dataset/224/gas)、[XJTU-SY Bearing Datasets](https://github.com/WangBiaoXJTU/xjtu-sy-bearing-datasets) 和 [NASA C-MAPSS](https://catalog.data.gov/dataset/cmapss-jet-engine-simulated-data)。本地优化和平台评分以赛方提供的 CPU 模型包及其公开划分为准；未接触隐藏标签。数据集、训练输出、密钥均未纳入公开 GitHub 源码或镜像。

## 5. 当前结论

本候选在同一套本地公开验证与 10 轮口径下，三组均优于直接 27B 续训检查点。隐藏集表现、平台对扩展检查点的加载方式，以及稳定性，需要新版平台试运行核实。正式成绩以平台报告为准。
