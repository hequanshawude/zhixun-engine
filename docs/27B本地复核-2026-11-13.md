## 分组与扰动检查

B 的 27B 候选相对原 v2 预测器，Bearing1_4 的 RMSE 从 335.220 升到 337.632，Bearing2_4 从 366.802 降到 347.197，Bearing3_4 从 579.134 降到 576.508。三个公开验证轴承中有一个退步，不能凭合并 RMSE 断言隐藏设备也会受益。输入加入固定种子的 1% 特征尺度噪声时，合并 RMSE 从原 v2 的 557.911 降到 555.260。

C 将原 v2 与本次 27B 预测器按 3:1 融合，公开验证 RMSE 从 50.089 轻微下降到 50.082，但扰动 RMSE 从 50.902 升至 50.908；不采用这点微小收益。此前另一个 27B 残差候选的公开验证 RMSE 为 49.829，但扰动 RMSE 约 54.0；即使只混入 10%，公开验证 RMSE 为 50.041，扰动 RMSE 也升至 50.975，因此暂不采用。

另试过防止 27B 在同一已采纳检查点上重复选择参数。该对照在 B 完成 10 轮、6,705 Token，但基础检查点只有 625.669，树修正未通过分组闸门。该策略改动已撤回；它能减少重复，却没有证据证明能提高成绩。

本机测试还用正式 JSONL 预测入口各抽取 64 条 B、C 验证样本，均返回有效数值。原始结果见 `out/local-27b-strict-20261113/`，其中 `ensemble_check.json` 和 `c_risky_blend_check.json` 记录上述融合与扰动数值。公开验证集已参与选择，且 B 只有 3 台独立验证轴承；这里的改善不能代替隐藏测试成绩。
