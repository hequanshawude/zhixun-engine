# Gas 真实数据初测（2026-11-10）

后续已通过 PyTRiO 训练权重完成真实 Gas 数据流对照，见[PyTRiO 训练权重与 Gas 对照](PyTRiO训练权重与Gas对照.md)。以下保留最初 27B 服务不可用时的原始结果。

## 数据和切分

来源：[UCI Gas Sensor Array Drift Dataset](https://archive.ics.uci.edu/dataset/224/gas)。将官方 `batch1.dat` 至 `batch10.dat` 按原顺序转换为 `data/processed/gas/batch_001.csv` 至 `batch_010.csv`，共 13,910 条、128 维、6 类；原标签 1～6 映射为 0～5。转换清单见 `data/processed/gas/manifest.json`，原始 ZIP 和来源哈希见 `data/raw/gas/download.json`。

第一批 445 条用于初始化；其余九批按原顺序先预测，再在本地带标签模拟中评估与更新。每批静态模型和动态模型面对相同样本。特征不含标签；这一方案用于准备阶段，当前批标签何时对赛方系统可见仍待官方协议确认。

两者使用同一个第一批训练模型：LightGBM，80 棵树、15 个叶子、随机种子 42。千问策略模型配置为 PyTRiO `Qwen/Qwen3.8-27B`，最多 6000 token 的本地策略预算。配置见 `configs/gas-pytrio.yaml`。

## 本次结果

运行记录：`runs/gas-pytrio/run-gas-20261110-152413-e27a7a05/`。

| 指标 | 固定模型 | 动态系统 |
|---|---:|---:|
| 九批 macro-F1 简单平均 | 0.3544 | 0.4894 |
| 差值 | — | +0.1350 |
| 新模型晋级次数 | 0 | 4 |

这个差值来自本地**规则策略**，不能归因于千问。PyTRiO 接口在全部三次实际策略请求中返回 HTTP 错误，之后系统熔断，九批决策都由本地规则完成，消耗 0 个有记录的 LLM token。紧接着单独做一次最多 16 输出 token 的短请求，返回 **HTTP 503**。首三次失败的 HTTP 状态未在原始逐批记录中保留，不能将其都断言为 503；未知是否产生服务端计费，应以平台账单为准。平台先前的小规模模拟实验已验证接口可成功回复，但本次真实数据实验**没有获得千问与固定模型的有效对照**。

`summary.json`、`decisions.jsonl`、`costs.json` 保存完整本地记录。九批平均分不等于官方赛题分；没有官方基线、最终切分和成本加权评分依据，不应宣称达到提交门槛。
