# SwanLab 云端实验

账号：`hequan`；私有项目：`zhixunyinqing`。

## 以后怎么运行

双击项目根目录 **run-cloud.cmd**。它会使用项目专用 Python 环境，运行 14 批混合漂移合成数据，并上传指标、脱敏配置、逐批决策及结果摘要。首批用于初始化，因此有 13 批预测和评估记录。

结束时打开窗口中的“云端实验”链接。每次运行创建一条新实验。需要保持联网和 SwanLab 登录有效；遇到上传异常会明确报错，本地记录保留在 `runs/cloud`。

若需要重新登录，双击 `login-cloud.cmd`，在窗口中粘贴官网 API Key。密钥无需写入 `configs/cloud.yaml`。
